# AURA fashion imagery

Original images generated with the built-in imagegen tool for this store mockup.

- Two campaign photographs for the split and full-width hero layouts.
- Three category photographs: outerwear, knitwear, and accessories.
- Eight products, each with front, detail, back, and on-model views.
- One atelier process photograph for the journal.

The product views share a warm ivory studio backdrop. Campaign and category imagery use muted architectural settings and natural light. Gallery variants use each product's front photograph as a design reference.

`../AURA Store.dc.html` supplies local `src` values for every image slot. Catalog, cart, checkout, and gallery thumbnails reuse the matching product assets. The image slots remain replaceable and reframable through the existing controls.

Full generation prompts are recorded in `prompts.json`.
